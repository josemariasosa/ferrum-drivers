# ferrum-rp2350

Experimental RP2350 hardware adapters for Ferrum Drivers. The current
`dht11` feature provides a DHT11 adapter for compatible GPIO pins and TIMER0.
The `pico2_dht11` example demonstrates the Raspberry Pi Pico 2 integration.
